# LinkaVel Logic Specification Ver 1.5

このドキュメントは、MASTER_CARDS の logic プロパティにおける共通規格を定義したものである。
プログラム側（EffectLogic）は、以下の定数およびパラメータを読み取って処理を実行する。

## 1. Trigger (発動条件)
効果がスタックに積まれるタイミングの定義。

- on_summon: 通常召喚・特殊召喚の着地成功時に発動。
- on_activate: 通常魔術・永続魔術の発動宣言時に発動。
- on_sent_to_trash: カードがトラッシュへ送られた瞬間に予約。
    フィールドからの破壊・召喚コスト・mill・手札からの捨て札のいずれでも発動する。
    ただし【除外】では発動しない（除外はトラッシュを経由しないため）。
- ignition: 自分のメインフェイズの「オープンな状態」でプレイヤーが任意に発動（バトルフェイズ不可）。
- always: フィールドに存在する限り、常時計算に介入（永続・オーラ）。
- after_combat: 戦闘（ダメージ計算）が終了したステップで発動。
- on_lp_gain: プレイヤーのLPが回復した瞬間に割り込み発動。
- on_other_sent_to_trash: 自分以外のカードがトラッシュに置かれた時に発動。
- on_battle_destroy: このモンスターが戦闘で相手モンスターを破壊した時に発動。
    攻撃側・防御側のどちらで破壊した場合も誘発する。
    発動元と同じ側のプレイヤーのカードが送られた場合のみ反応し、
    action.filter に合致するカードでなければ発動しない（相手の破壊では誘発しない）。

### 1-2. 罠魔術のトリガー
セットされた罠魔術のみが使用する。条件を満たすと強制的に自動発動する。

- on_opponent_summon: 相手がモンスターを召喚・特殊召喚した時。
    複数体が同時に特殊召喚された場合も、まとめて1回だけ判定する。
- on_opponent_attack: 相手が攻撃を宣言した時。ダメージ計算より前に解決する。
- on_own_monster_destroyed: 自分のモンスターが破壊されトラッシュへ送られた時。

## 2. Action Type (命令種別)
実行される具体的なプログラム処理。

- buff: 対象のパワーを数値分加算/減算する。
- global_buff: フィールドの複数体（フィルタ合致者）のパワーを一括変更する。
- special_summon: デッキ・トラッシュからモンスターをフィールドの空き枠に展開。
- draw_card: デッキから指定枚数カードを手札に加える。
- draw_and_discard: ドロー実行後、指定枚数を手札から選んで捨てる一連の処理。
- mill: デッキトップから指定枚数をトラッシュへ移動する。
- search: デッキから条件に合うカードを手札に加える（シャッフルを含む）。
- salvage: トラッシュから条件に合うカードを手札に加える。
- heal: プレイヤーのLP数値を増加させる。
- destroy: 対象カードを破壊し、フィールドからトラッシュへ移動させる。
- battle_protection: 戦闘破壊を無効化するフラグ（1ターンに1度等）を付与。
- damage_reduction: プレイヤーが受ける戦闘ダメージを数値分軽減する。
- bounce: 対象のモンスターを持ち主の手札へ戻す。
- damage: 相手（または自分）のLPを数値分減らす。戦闘ダメージ軽減の影響を受けない。
- destroy_magic: 魔術ゾーンのカードを破壊する。伏せられたカードも対象にできる。

## 3. Parameter & Filter (詳細パラメータ)
各アクションに付随する制御用の属性。

- targetSide: self (自分) / opponent (相手)
- targetSelect: random (システム自動) / manual (UI選択) / all (全体)
    罠魔術では「誘発元」を対象にできる:
    - event: 誘発の原因になったカード（召喚されたモンスター／破壊されたモンスター）
    - event_attacker: 攻撃してきた相手モンスター
    - event_defender: 攻撃対象になった自分のモンスター
- source: deck / trash / choice_deck_or_trash / event
    event は「誘発元になったそのカード」を指す（破壊されたモンスターの蘇生など）。
- countLimit: once_per_turn (1ターンに1度) の制限管理。
- cost: アクションの発動に必要な支払い。払えない場合そのアクションは発動しない。
    - discardHand: N … 手札をN枚トラッシュに送る（プレイヤーは選択、CPUは自動）
    - banishTrash: N … 自分のトラッシュのカードをN枚除外する
- optional: true (任意発動 - プレイヤーに確認) / false (強制発動)。
- duration:
    - until_end_turn: 発動したターンのエンドフェイズまで。
    - until_opponent_end: 次の相手ターンのエンドフェイズまで。
    - permanent_aura: そのカードが場に存在する限り継続。
- condition:
    - is_weakened: 現在の実数値（常時オーラ・一時バフをすべて含む getCurrentPower の値）が
        印刷されたパワーより低い場合。「森界の門」のような常時デバフも対象に含める。
        （例: 森界の門で相手全体が-200されている間は、相手モンスターは常にこの条件を満たす。
        森界の怒りとの組み合わせは【森界】デッキの意図した除去手段であり、バグではない）
    - is_opponent_turn: 相手ターンの間のみ。
    - has_category_on_field: 特定の【カテゴリ】が自分フィールドに存在する場合。

- condition (オブジェクト形式 / 罠魔術の誘発条件):
    文字列ではなくオブジェクトを渡すと、誘発元の情報に対する条件として扱われる。
    すべてのキーを満たした場合のみ発動する。
    - summonedFilter:  召喚されたモンスターに1体でも合致するか（filter と同じ書式）
    - attackerFilter:  攻撃モンスターが合致するか
    - defenderFilter:  攻撃対象の自分モンスターが合致するか
    - destroyedFilter: 破壊されたモンスターが合致するか
    - attackerWeakenedBy: 印刷されたパワーと現在の実数値の差が N 以上か。
        is_weakened と同じ基準（常時オーラ込み）で判定する。

## 4. 解決シーケンス (Resolution Priority)
1. 効果解決の開始: 配列内の Action をインデックス順にすべて実行（非同期割り込み禁止）。
2. 誘発予約: 処理中に発生した「トラッシュ送り」等のイベントはすべてキューに溜める。
3. 連鎖解決: 全ての Action が終了し、フィールドが静止した後にキュー内の誘発効果を開始する。

## 5. カードの移動と個体状態

カードには実行中の一時状態（_tempBuffs / _hasAttacked / _usedLimits 等）が付く。
場を離れる際は必ず main.js の共通経路を通し、これらを消してから移動させること。

- sendCardToTrash(side, card): トラッシュへ送る。個体状態をリセットする。
- banishCard(side, card): 除外する。個体状態をリセットする。復帰手段はない。
- EffectLogic.notifyCardSentToTrash(card, side): トラッシュ送りに伴う誘発をまとめて処理する。
    自身の on_sent_to_trash と、フィールド上の他カードの on_other_sent_to_trash を解決する。
    トラッシュへ送る処理を書いたら必ずこれを呼ぶ（除外では呼ばない）。

これを通さないと、蘇生したモンスターが「攻撃済み」のままだったり、
デッキリフレッシュで古いデバフを引きずったカードが山札に戻る。

## 6. 効果解決時の安全装置

- 解決の深さは MAX_RESOLVE_DEPTH (12) までに制限される。
  特殊召喚が連鎖して循環した場合でも、そこで打ち切られる。
- プレイヤーが対象選択をキャンセルした場合、そのカードの残りの Action は実行されない。
  「自分と相手を1体ずつ破壊」のような効果で、自分側だけ回避されるのを防ぐため。
- targetSelect: "manual" の対象選択では、action.filter と condition を満たすスロットだけが
  選択可能になる。条件外のカードは選べず、選んで不発になることがない。
- countLimit: once_per_turn の使用済み判定は EffectLogic の _usedLimits に一本化されている。
  UI・CPU は EffectLogic.isIgnitionUsed(card) で参照すること（独自フラグを持たせない）。

## 7. 罠魔術の実装メモ

- セットされたカードは `_isSet: true` と `_setTurnSerial`（伏せた手番の通し番号）を持つ。
  `GAME_STATE.turnSerial` は手番交代のたびに必ず +1 される。
  `_setTurnSerial === GAME_STATE.turnSerial` の間は発動できない（伏せたターンは使えない）。
- 誘発点は main.js から以下の3つを呼ぶ。追加したイベントで罠を反応させたい場合はここに足す。
    - EffectLogic.notifySummon(side, cards)                      … 召喚・特殊召喚の直後
    - EffectLogic.notifyAttackDeclared(side, atk, i, def, j)     … 攻撃宣言時（true が返ったら戦闘を中止する）
    - EffectLogic.notifyMonsterDestroyed(side, card)             … 破壊されてトラッシュへ送られた直後
- 解決中は EffectLogic._eventContext に誘発元の情報が入る。
  targetSelect: "event*" と source: "event" はここを参照する。
